Help center

Frequently asked questions

Is this the official RaTIX download?

Yes. This portal links to releases published in the official RaTIX-Releases GitHub repository.

Android blocks the installation. What should I do?

Use Android Settings to allow installation for the browser or file manager you used to open the APK. Only proceed if the file came from the official RaTIX release page.

How do I update RaTIX?

Check the app's update function or return to this portal and download the latest published release.

Where can I see previous versions?

Open the RaTIX Releases page to view published versions and their release notes.
